## Key Discussion Topics

### NDA Scope and Intellectual Property

**Core Agreement:**
- Both parties will share confidential information (business processes, methodologies, data)
- NDA protects proprietary information from third-party disclosure
- Both parties maintain ownership of pre-existing IP

**IP Ownership Principles:**
- **Raw Data:** Shared ownership between both parties (e.g., Liberty Hill project data, schedule of values)
- **Vermeulens IP:** Parametric calculation tools, cost manipulation algorithms ("how the radio works")
- **Pfluger IP:** Project Prism platform UI/UX, workflow, client interface
- **Data vs. Intelligence:** Pfluger gets access to cost outputs and can "turn the dials," but Vermeulens retains the underlying calculation methodologies

**Third Party Involvement:**
- Vermeulens works with guidance/data partners for formatting
- All third-party information remains confidential under NDA

### Collaboration Scope

**Geographic and Market Limitations:**
- **Primary Focus:** K-12 education in Texas
- **Excluded:** Higher education (currently Vermeulens working independently with UT, A&M systems)
- **Future Expansion:** By mutual agreement only
  - Could expand to other states (Colorado, Boston, etc.) if both parties agree
  - Could expand to higher ed if opportunity arises (e.g., Texas Lutheran, A&M system)
  - Any expansion requires case-by-case discussion

**Rationale for K-12 Texas Focus:**
- Pfluger doesn't foresee expanding beyond K-12 in foreseeable future
- Vermeulens maintains existing higher ed client relationships independently
- Allows both parties to focus efforts and avoid conflicts

### Technical Platform Integration

**Current Understanding:**
- Vermeulens has existing parametric cost estimation tool
- Integration approach: Embedded tool (like Power BI iframe) within Pfluger's platform
- Pfluger provides UI/UX, project workflow, mapping, visualization
- Vermeulens provides cost calculation engine with interactive parameters

**User Experience:**
- Users can adjust variables (building type, HVAC systems, construction methods)
- Vermeulens maintains back-end calculation logic
- Pfluger's platform hosts the interface and presents results
- "Powered by Vermeulens" attribution in platform

**Data Maintenance:**
- Vermeulens responsible for updating cost data (escalation factors, material costs, system costs)
- Updates needed monthly due to market changes (steel rates, HVAC systems, etc.)
- Static values for program types already provided by Vermeulens (from Yale, Dallas data)

### Business Model and Revenue

**Pfluger's Value Proposition:**
- Tool differentiates Pfluger in competitive proposals
- Enables new fee structures for services not currently charged
- Improves bond planning process quality
- Helps win work that might otherwise go to competitors
- Access to cost data for better client service

**Vermeulens' Value Proposition:**
- Access to Texas school district data for benchmarking
- Entry to K-12 clients through Pfluger relationships
- Expectation of estimating work on Pfluger projects
- Product development experience and broader data collection

**Revenue Scenarios Discussed:**

1. **Ideal Scenario:** Vermeulens provides cost data/tools in exchange for:
   - Access to project data
   - Estimating contracts on Pfluger bond planning projects
   - Cost built into Pfluger's bond planning fees

2. **Alternate Scenario:** If estimating relationship doesn't work out:
   - Discussion needed about licensing fees for tool usage
   - Some form of compensation required if not getting estimating work
   - Exact structure TBD

3. **Licensing Discussion:**
   - If tool is "built together," Pfluger could have license to use indefinitely
   - Someone else could provide escalation data updates
   - Tool functionality would remain but become dated without Vermeulens' maintenance

### Data Ownership and Portability

**If Partnership Ends:**
- Raw project data (Liberty Hill, etc.) remains accessible to both parties
- Vermeulens retains parametric calculation methodologies
- Pfluger could continue using tool but would need new data provider
- Tool would function but become outdated without ongoing maintenance
- Pfluger would need time to transition to alternative cost data provider
- Need for continued functionality during transition period

**Data Usage Rights:**
- Vermeulens can use Texas school data across projects for improved estimates
- Data collected through Pfluger projects can be used by Vermeulens (with proper attribution)
- If partnership dissolves, data collected through collaboration should be available to Pfluger for new cost estimator

## Important Decisions/Agreements

1. **Scope Limitation:** K-12 education in Texas only, unless both parties collectively agree to expand elsewhere

2. **IP Separation:**
   - Vermeulens owns parametric calculation methodologies
   - Pfluger owns platform UI/UX and workflow
   - Raw project data is jointly owned

3. **Platform Integration:** Embedded tool approach (Vermeulens calculation engine within Pfluger interface)

4. **Pre-Existing Work:** Both parties can continue existing platforms/tools developed before collaboration

5. **Revenue Model Primary Path:** Vermeulens compensated through estimating work on Pfluger projects, with costs built into bond planning fees
